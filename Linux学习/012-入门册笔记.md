# 2026/11/13 - 11/14 ｜ Linux入门 第 2 章 文件与目录操作
**学**
- mkdir 创建新目录
- mkdir -p 逐级创建
- touch 创建空文件(有文件时是更新时间戳)
- cp 复制
- cp -r 带目录时要逐级复制
- mv 移动/改名
- rm 删除
- rm -r 逐级删除
- rm -f 强制删除 不提示
- rm -rf 强制删除
- rmdir 
**坑/须知**
1. 创建目录时最好带-p逐级创建 无目录时自己创建而不报错
2. rm -rf谨慎用
3. 做事之前记得备份 cp
4. 复制目录是也记得带-p 都带上 否则会报错
5. mv 目标存在直接覆盖
