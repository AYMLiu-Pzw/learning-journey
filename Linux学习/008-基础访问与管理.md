# 2026/11/7 - 11/8｜ 外部资料 labex 2-4 堡垒守卫者 (权限设置)
**学**
- chmod xxx 目录  给目录设置权限 
- x/x/x 所有者/组用户/其他人
- chown user:group 更改用户和组 所有
- chmod xxxx  这单比设置权限多了个设置特殊位 就是开头的第一个 

**坑/须知**
- 设置chown 时 应该是 `用户:组 目录` 如果只有用户就 `用户 目录` 只有组就`:组 目录`
**精译**
1. 读,写,执行 / r,w,x / 4,2,1 
2. [chown user:group 更改用户和组 所有] 这个和chmod区别就是一个设置哪些人的权限 一个是把这个文件给哪些人吧 不然只给了权限 没给谁用不就白设置了
3. 0770：特殊位为 0；普通权限是 770  
1770：设置 sticky 位（值为 1）常用于共享目录，限制用户只能删除或重命名自己拥有的文件；它不会让新文件继承目录的组  
2770：设置 setgid 位（值为 2）让目录中新建内容继承 developers 组  
3770：同时设置 sticky（1）和 setgid（2），因为 1 + 2 = 3  
**卡住**
- 这个chown 可以单设置给用户或组 不用都给设置
