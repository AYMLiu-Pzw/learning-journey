**精译**
1. 
uid=xx(yy)：你的用户 ID 是 xx，用户名为「yy」
gid=xx(yy) 你的主组 ID 是 xx，组名为「yy」
groups 你属于多个组

2. 使用 > 运算符重定向第一个命令的输出 该操作会创建文件；如果文件已经存在，则会覆盖原有内容  
使用 >> 运算符将后续命令的输出追加到文件中，不会删除已有内容
