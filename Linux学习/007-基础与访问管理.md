# 2026/11/6 - 11/7｜ 外部资料 labex 2-3 日志调查员
**学**
- dmesg 用于显示内核消息
- | 管道符 将一个命令的输出发送到另一个命令的输入
- grep -i 忽略大小写
- grep -E 搜索多个目标
- > 将内容覆盖到一个文件内
- >> 将内容追加到文件
- diff 对比文件非一致的地方
- diff -r 比较目录
**坑/须知**
- grep -E 选多个目标时用“|”区分
- diff A B 与 diff B A 会产生不同的输出 
**精译**
1. diff 语法是 diff file1 file2，它会显示需要对 file1 做哪些更改，才能使其`与 file2 完全一致` （所以还是与file2对齐）
2. 对目录使用 diff 时，输出会明确指出哪些文件「Only in」某个目录
