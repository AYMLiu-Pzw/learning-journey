# 2026/11/09 - 11/xx ｜外部资料 labex 2-5 钥匙守卫者
**学**
- useradd <name> 创建新用户
- useradd -m <name> 创建新用户并创建主目录
- userdel <name> 删除用户
- passwd <name> 设置密码
- usermod -aG <组> <用户> 将用户追加到组
- usermod -L 锁定账户
**坑/须知**
1. 创建新用户时要记得带-m 不然新用户没有主目录使用
2. 主目录将归该用户所有 要查看目录内容，你可能需要适当的权限，或使用 sudo
3. 设置密码时输入密码不显示是正常的 正常输两遍就好
**精译**
1.用户详细信息可以用 grep "<name>" /etc/passwd 看
2. usermod 选项 -a（追加）-G（组）
3. useradd 的 -m 表示自动创建新用户的主目录 也可以把目录名字换成自己想要的样子
