# 2026/11/2 - 11/2 ｜ 外部资料 labex 1-9

**做**
- sudo 给予临时管理权限
- useradd name 创建新用户
- useradd -m name 创建一个带主目录的用户
- passwd name 设置密码
- usermod 修改用户设置
- usermod -d /home/xxx 用户名 >指定新的目录
- usermod -s /bin/shell 用户名 >给用户换shell
- usermod -ag sudo 用户名 >-ag是加入到组 sudo是加入到的组
- groups name 查看name的属组
- us - name 切换到name
- passwd -l name 冻结用户
- usermod -u name 解冻用户 
- userdel -r name 删除name
**坑/须知**
- 一般文件用户文件都在/home/
- /etc/passwd 文件夹像是账户电话薄 不同信息用 ':' 区分
**精译**
1. sudo grep -w 'joker' /etc/passwd  
=> joker:x:5001:5001::/home/joker:/bin/sh   
用户名：joker  
密码：x（实际密码安全地存储在其他位置）  
用户 ID：5001   
组 ID：5001  
主目录：/home/joker，但该目录尚未创建  
默认 Shell：/bin/sh  
2. sudo ls -ld /home/bob  
=> drwxr-x--- 2 bob bob 57 Jan 19 13:33 /home/bob  
开头的 d 表示这是一个目录  
rwxr-x--- 表示哪些用户拥有读取、写入或执行该目录的权限  
两个 bob 表示该目录的用户所有者和组所有者都是 bob  
57 表示目录大小，单位为字节  
Jan 19 13:33 表示目录的创建时间  
/home/bob 表示目录的位置
