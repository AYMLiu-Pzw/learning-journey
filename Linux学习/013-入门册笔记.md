# 2026/11/14 - 11/15 ｜ Linux入门 第 3 章 查看与搜索
**学**
- grep "内容" 文件 查找文件内的指定内容 
- grep -i 无视大小写
- grep -c 只查有多少行和指定内容匹配
- grep -v 反向筛查(显示去掉指定内容后剩下的内容)
- grep -n 显示行号
- grep -r 搜索整个目录
- less 找大型文件时推荐用
- cat 查看文件内容
- head -n行号 查看前多少行(不带行默认前10)
- tail -n行号 查看后多少行
- tail -f 实时查看新增的内容
- find 找名字方便 可以查文件名大小和类型
- find 目录 -type f 只看普通文件
- wc -l 查看有多少行数
- wc -w 看词数
- wc -c 看字节
- file 看文件类型
- diff 1 2 对比1和2 看1比2<(多)\n --- \n>(少)什么
**坑/须知**
1. grep -v时 开头要-v "^要排除的东西" 只有开头生效
2. find使用时应要查看的文件在find后面
3. grep查内容 find查文件
4. 用less时 空格下翻 B上翻 q退出 还能搜索指定内容
5. diff 1 2 是以2为目标 <[比2多了] 和 >[比2少了] 什么
